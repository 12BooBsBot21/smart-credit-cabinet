# Умный кредитный кабинет предпринимателя

Прототип цифрового кредитного кабинета для малого и микробизнеса. Проект объединяет подачу кредитной заявки клиентом и её обработку на стороне банка.

## Структура проекта

- `frontend/` — клиентское приложение на React и TypeScript.
- `backend/` — серверная часть и API.
- `docs/` — документация проекта, описание API и архитектуры.

## Команда и совместная работа

- Работаем в общем Git-репозитории.
- Для новых задач создаём отдельные ветки.
- Изменения вливаем в `main` через Pull Request.
- Перед объединением проверяем изменения и работоспособность приложения.

## Запуск проекта

Инструкции по установке зависимостей и запуску frontend и backend будут добавлены после настройки окружения.
